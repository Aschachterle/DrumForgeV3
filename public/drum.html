E-Drum STL Generator

Welcome to the Extrudo Electronic Drum STL generator. I created this tool after realizing the retail cost of an electronic drum far exceeds the sum of its parts. Building your own is a great alternative that saves money and lets you craft a drum with a highly realistic size and appearance, completely bypassing the undersized pads major manufacturers usually offer.

I built this tool as a proof of concept using the Fusion 360 API and Autodesk Design Automation service. You can modify the parameters below to create a fully custom 3D printable drum shell and a matching sensor platform.

Already have a shell? You can skip printing the shell entirely. If you want to use a preexisting acoustic shell, simply enter its diameter, thickness, height, and lug hole parameters. The modeler will output a custom piezo sensor platform tailored exactly to your drum—just delete the shell STL and print the sensor platform.

Once you're happy with your settings, generate the final STL file for 3D printing. Note: I'm currently using a developer license, so the tool may temporarily pause if API usage limits are reached.

Additional Parts & Materials

You'll need these items to complete your drum build.

🥁
Mesh Drumhead Sized to match your shell diameter. I used a Remo Silentstroke.
🔩
Drum Lugs Quantity: 2× the number of shell segments (e.g., 6 lugs for 3 segments)
🧪
CA Glue (Super Glue) For bonding the lap joints between shell segments
📄
Sandpaper For smoothing lap joints before gluing (150-220 grit)
⚡
27mm Piezo Sensor Main trigger sensor - mounts to the center platform
⚡
37mm Piezo Sensor Rim trigger sensor (optional for dual-zone)
⚡
Female Stereo Output Jack 1/4" TRS jack for connecting to your drum module
⭕
Drum Hoop Sized to match your shell diameter
🔘
Rubber Drum Hoop Cover Protects sticks and reduces rim noise on cross-stick hits
🔺
Foam Piezo Sensor Cone Transfers input from the drumhead to the piezo sensor
